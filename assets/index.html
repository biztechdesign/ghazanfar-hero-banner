SVG assets

The khatam lattice and the Ghazanfar mark, as standalone SVG files. The pattern geometry is generated by the same maths as the animated hero, so the static and animated versions line up exactly.

Pattern — seamless tile at 1×

One 104×104 tile repeating. The star sits on the grid corners, so it is drawn at all four corners of the tile and the edges meet with no seam. Cross in the middle of every cell.

Pattern — same tile at 3×, to check the joins

ghazanfar-mark-currentcolor.svginline only · inherits colour

currentColor only resolves when the SVG is inline in the document — both cards above are inlined, which is why they pick up the gold from their parent. Through <img> or url() the browser renders the file in its own isolated document where there is nothing to inherit, so use the fixed-colour files there.
